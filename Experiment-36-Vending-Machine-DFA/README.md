# Vending Machine Simulation using DFA

## Aim
To simulate a vending machine utilizing DFA concepts.

## Theory
A vending machine changes states based on coins inserted and dispenses an item when a threshold state is reached.

## Algorithm
1. Define states as total money inserted.
2. Loop inputs (coins).
3. If money >= price, dispense and return change.
