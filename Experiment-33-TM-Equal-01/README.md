# Turing Machine for Equal 0s and 1s

## Aim
To simulate a TM for strings with an equal number of 0s and 1s.

## Theory
The TM finds a 0, marks it, finds a 1, marks it, and repeats until all are marked.

## Algorithm
1. Scan right to find '0', mark as 'X'.
2. Scan right to find '1', mark as 'Y'.
3. Repeat until no unmarked characters are found.

The source code is provided in `program.c`.
