# CSA1308
**Formal Languages and Automata Laboratory**

## Project Overview
This repository contains the complete set of 42 laboratory experiments for **CSA1308: Formal Languages and Automata Laboratory**. 

Each experiment is organized into its own folder and includes:
- C Source Code (`program.c`)
- Sample Input (`input.txt`)
- Sample Output (`output.txt`)
- Terminal Screenshot (`screenshot.png`)
- Detailed Documentation (`README.md`)

*Note: Since execution environments vary, the `output.txt` and `screenshot.png` files are provided as placeholders. They should be regenerated on your local machine by compiling and running `program.c`.*

## How to Run

### Clone
```bash
git clone https://github.com/Hemanth-eng877/CSA1308.git
cd CSA1308
```

### Compile
Navigate to any experiment directory and compile the C program using GCC:
```bash
cd Experiment-01-DFA-Start-End-a
gcc program.c -o program
```

### Execute
Run the compiled executable and provide the input from `input.txt`:
```bash
# On Linux / Mac
./program < input.txt > output.txt

# On Windows
program.exe < input.txt > output.txt
```
*After running, capture the terminal output and replace `screenshot.png`.*
