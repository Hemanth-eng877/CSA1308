# Turing Machine for Multiplication

## Aim
To write a C program simulating a TM for unary multiplication.

## Theory
Unary multiplication of n and m. The TM copies the block of m '1's exactly n times.

## Algorithm
1. For every '1' in n, append m '1's to the output section.
2. Erase the original n and m.
3. Output the result.

## Program
The source code is provided in `program.c`.

## Sample Input
```
110111
```

## Sample Output
