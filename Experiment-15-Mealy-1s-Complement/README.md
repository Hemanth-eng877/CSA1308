# Mealy Machine for 1's Complement

## Aim
To implement a Mealy machine that outputs the 1's complement of a binary string.

## Theory
A Mealy machine's output is determined by its current state and current input. For 1's complement, output 1 for input 0, and output 0 for input 1.

## Algorithm
1. Read input binary string.
2. For each character, if '0' output '1', if '1' output '0'.
3. Single state is sufficient.

## Program
The source code is provided in `program.c`.
