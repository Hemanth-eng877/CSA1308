# Turing Machine to Reverse a String

## Aim
To write a C program simulating a TM reversing a string.

## Theory
A TM can push characters to the end in reverse order or swap ends.

## Algorithm
1. Swap leftmost unmarked with rightmost unmarked.
2. Repeat until pointers cross.

## Program
The source code is provided in `program.c`.
