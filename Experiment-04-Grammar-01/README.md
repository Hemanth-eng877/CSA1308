# Grammar Checker for specific language

## Aim
To write a C program to check if a string belongs to a specific grammar.

## Theory
A grammar consists of a set of rules used to generate strings in a language. Here we simulate checking against a simple regular grammar.

## Algorithm
1. Take input string.
2. Parse through the string to match the grammar pattern (e.g. all a's followed by all b's).
3. If valid, accept; else, reject.
